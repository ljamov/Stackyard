AI-ready

Let your AI coding tool see your stack

Stackyard has a built-in MCP server for Claude Code, Cursor, Claude Desktop, Windsurf and others. AI tools can list sites, services and runtimes and read logs. Starting services, creating sites and changing versions stay off until you allow them, and deleting is never offered. Every call is logged.

# connect Claude Code to Stackyard
$ claude mcp add --scope user stackyard -- stackyard mcp

# allow one action
$ stackyard mcp allow start_service

# see what AI tools did
$ stackyard mcp log
$ stackyard system setup        # domains and HTTPS
$ stackyard sites park ~/Code   # every folder is a site
$ stackyard runtimes install php 8.4
$ stackyard use php 8.3         # pin this project
$ stackyard start               # run it all
